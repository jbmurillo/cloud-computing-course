#Cloud Concepts Reflection

Cloud computing is part of my everyday life because I use many online services for school and personal tasks. Three cloud services that I use often are Google Drive, Facebook Messenger, and Canva. These services help me save files, communicate with my friends and classmates, and make presentations or posters for activities

Google Drive is a Software as a Service (SaaS) because I can use it online without installing or managing any software or servers. It uses the Public Cloud because anyone with a Google account can access it. Facebook Messenger is also SaaS because Meta provides the application, and I only need an internet connection to use it. It is also a Public Cloud service because it is available to users around the world. Canva is another SaaS application because it lets me create designs online without installing special software. It also uses the Public Cloud since many people can use it through the internet.

Version control is important when working on cloud projects because it keeps a record of every change made to files and code. If someone makes a mistake, the team can go back to an older version instead of starting over. This saves time and helps avoid problems.

Git and GitHub make it easier for teams to work together on the same project. Every member can make changes, and GitHub records who made them and when. It also helps compare different versions of files and makes it easier to fix mistakes. Because of these features, GitHub helps teams stay organized, work better together, and build cloud projects more safely and efficiently.
